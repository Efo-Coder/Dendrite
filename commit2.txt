feat: User-Profilverwaltung, Glass-UI-Überarbeitung & NoteList-Verbesserungen

## Backend

- Drei neue Auth-Endpunkte hinzugefügt:
  - PUT /auth/profile  → Anzeigename aktualisieren
  - PUT /auth/password → Passwort ändern (mit Validierung & bcrypt)
  - DELETE /auth/account → Konto vollständig löschen
- auth.routes.ts entsprechend erweitert

## Frontend – Auth

- authService um updateProfile, changePassword und deleteAccount ergänzt
- useAuthStore spiegelt die drei neuen Aktionen wider; deleteAccount ruft
  anschließend automatisch logout() auf
- Neue UserProfileModal-Komponente für die Profil- und Passwortverwaltung

## Frontend – CSS / Design-System

- Dark-Mode-Glassvariablen (--glass-bg, --glass-bg-strong, --glass-bg-soft)
  nutzen jetzt color-mix() statt fest kodierter rgba-Werte → passen sich
  automatisch ans aktive Theme an
- Hintergrundgradient der App verwendet jetzt Theme-Variablen statt
  hardcodierter Dunkelfarben
- --glass-bg-strong im Light Mode auf rgba(255,255,255,1) gesetzt
- Neue Utility-Klassen: .btn-subtle, .glass-header, .auth-inputs
- .btn, .input, .card, .glass-panel* von @apply auf plain CSS migriert
  (bessere Safari/Tailwind-Kompatibilität)
- Verbessertes Placeholder-Styling via ::placeholder + color-mix()
- Native MS-Edge/IE Passwort-Anzeige-Button per CSS ausgeblendet
- Neue Hintergrundbilder: dendrite-forest.jpg, pine-watt-bg.jpg

## Frontend – Login- & Registrierungsseite
